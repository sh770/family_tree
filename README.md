# שלשלת — עץ משפחה חי על GitHub Pages

אתר עץ משפחה סטטי שמתעדכן דרך GitHub Actions. כל אחד יכול לבנות טיוטה פרטית
בדפדפן שלו (localStorage), ולשלוח אותה כ-Issue ב-GitHub לאישור מנהל/ת העץ.
כשהאישור ניתן (הוספת התווית `approved`), GitHub Action מטמיע את השינוי
בקובץ `data/family-tree.json` וכולם רואים אותו באתר החי.

## מבנה הפרויקט

```
index.html                                  # כל האתר (תצוגה, טופס, טיוטות)
data/family-tree.json                       # "מקור האמת" - הנתונים החיים
.github/ISSUE_TEMPLATE/update-request.yml    # טופס ה-Issue שהאתר פותח
.github/workflows/apply-approved-update.yml  # ה-Action שמטמיע עדכון מאושר
scripts/apply-update.mjs                     # הלוגיקה שמעדכנת את ה-JSON
```

## התקנה (פעם אחת)

1. **צרו ריפו חדש ב-GitHub** (ציבורי, כדי שאפשר יהיה לפתוח בו Issues בלי הרשאות
   מיוחדות) והעלו אליו את כל התיקייה הזו.

2. **עדכנו את שם הריפו בקוד** — בקובץ `index.html` שנו את השורה:
   ```js
   const REPO = "YOUR-GITHUB-USERNAME/family-tree";
   ```
   לשם המשתמש/ארגון ושם הריפו האמיתיים שלכם.

3. **הפעילו GitHub Pages**:
   Settings → Pages → Source: `Deploy from a branch` → Branch: `main` / `root`.

4. **תנו הרשאות כתיבה ל-Actions** (כדי שה-workflow יוכל לבצע קומיט):
   Settings → Actions → General → Workflow permissions →
   בחרו **Read and write permissions** ושמרו.

5. **וודאו שהתווית `approved` קיימת** ברשימת ה-Labels של הריפו
   (Issues → Labels). אם לא — צרו תווית חדשה בשם `approved`.

זהו. האתר יהיה זמין בכתובת `https://YOUR-GITHUB-USERNAME.github.io/family-tree/`.

## איך משתמשים בזה

- **כל אדם**: נכנס לאתר, בונה טיוטה פרטית (נשמרת רק אצלו בדפדפן), ואם רוצה
  שהיא תיכנס לעץ הציבורי — לוחץ "שליחה לאישור מנהל". זה פותח טופס GitHub
  Issue ממולא מראש (דורש חשבון GitHub חינמי).
- **מנהל/ת העץ**: מקבל/ת התראה על Issue חדש, בודק/ת את התקציר, ואם תקין —
  מוסיף/ה את התווית `approved`. תוך דקה העדכון נכנס לקובץ הנתונים והאתר מתעדכן.
- **דחיית בקשה**: פשוט סוגרים את ה-Issue בלי להוסיף את התווית.

## סנכרון תאריכים עברי / לועזי

הפרויקט משתמש בספריית [`@hebcal/core`](https://www.npmjs.com/package/@hebcal/core)
האמיתית לסנכרון תאריכים:

- **באתר**: נטענת דרך `https://esm.sh/@hebcal/core` ישירות בדפדפן (אין צורך
  בשלב build). בטופס "הוספה" מספיק להזין תאריך לועזי **או** עברי אחד —
  הצד השני מחושב ומוצג מיד כתצוגה מקדימה.
- **באישור**: `scripts/apply-update.mjs` מריץ את אותו חישוב בצורה **סמכותית**
  בזמן שה-GitHub Action רץ (`npm install` מתקין את `@hebcal/core` מ-`package.json`
  לפני ההרצה), כך שהקובץ הסופי תמיד עקבי בין שני הלוחות — גם אם מישהו שלח
  ידנית רק צד אחד.
- **בדשבורד**: אפשר לעבור בין "חודש לועזי" ל"חודש עברי" ולראות את כל
  האירועים (ימי הולדת, פטירה, נישואין, גירושין) שנופלים לאותו חודש, בכל
  שנה. **הערה על אדר**: מכיוון שבשנה מעוברת יש אדר א׳ ואדר ב׳, אירוע שנרשם
  ב"אדר" בשנה רגילה מוצג תחת האפשרות "אדר / אדר א׳" — זו הפשטה מכוונת,
  ולא פסיקה הלכתית לגבי מתי חוגגים יום הולדת שחל באדר בשנה מעוברת.

## הערות טכניות נוספות

- ילדים משויכים ל**זוג הורים ספציפי** (relationship), כדי לתמוך במשפחות עם
  כמה בני/בנות זוג לאורך זמן. בני זוג לשעבר מיוצגים כ-relationship נפרד
  עם סטטוס `divorced`.
- אין סיסמת מנהל בקוד — ההרשאה לאשר מבוססת על הרשאות GitHub האמיתיות של
  הריפו (מי שיכול להוסיף תוויות ל-Issues).
